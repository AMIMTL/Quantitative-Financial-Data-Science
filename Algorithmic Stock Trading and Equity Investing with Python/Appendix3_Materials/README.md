### NumPy Key Concepts
```python
import numpy as np

# Array creation
arr = np.array([1, 2, 3, 4, 5])
arr_2d = np.array([[1, 2], [3, 4], [5, 6]])

# Important: View vs. Copy
arr_slice = arr[1:4]  # View (modifies original!)
arr_copy = arr[1:4].copy()  # Copy (safe)

# Universal functions
np.sqrt(arr)
np.exp(arr)
np.sin(arr)
```

### Pandas Key Concepts
```python
import pandas as pd

# DataFrame creation
df = pd.read_csv('data.csv')

# Indexing
df.iloc[0:5, 0:3]  # Position-based (rows 0-4, cols 0-2)
df.loc['2020-01-01':'2020-12-31', ['Open', 'Close']]  # Label-based

# Filtering
df[df['Volume'] > 1000000]  # One condition
df[(df['Volume'] > 1000000) & (df['Close'] > df['Open'])]  # AND
df[(df['Volume'] > 1000000) | (df['Close'] > 100)]  # OR

# Handling missing values
df.dropna()  # Remove rows with NA
df.fillna(value)  # Fill with a value

# GroupBy - split-apply-combine
df.groupby('Symbol')['Close'].mean()
df.groupby(['Symbol', 'Year'])['Volume'].sum()
df.groupby('Symbol').apply(lambda x: (x['Close'] - x['Open']).mean())
```
