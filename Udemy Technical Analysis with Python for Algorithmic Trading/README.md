**Status:** 🔄 In progress

## Course Overview
This is a data-driven course on Technical Analysis. It goes beyond theory and rules, using rigorous backtesting and forward testing to identify and optimize trading strategies based on technical indicators. You will build Python frameworks to code and test thousands of trading strategies quickly.

## What You'll Learn

### Technical Indicators & Strategies
- Simple Moving Average (SMA) strategies
- Exponential Moving Average (EMA) strategies
- Moving Average Convergence Divergence (MACD) strategies
- Relative Strength Index (RSI) strategies
- Stochastic Oscillator strategies
- Bollinger Bands strategies
- Pivot Point strategies
- Fibonacci Retracement strategies
- Combined strategies (using multiple indicators)

### Python & Data Analysis
- Backtest and forward test trading strategies
- Create interactive charts (Line, Volume, OHLC, Candlestick) with Plotly
- Visualize indicators, trend lines, support and resistance levels
- Use Pandas, NumPy, and Object-Oriented Programming (OOP) for trading
- Load financial data from local files and the web
- Build a `Financial Instrument` class for reusable analysis

## Prerequisites
- **Not for complete Python beginners**
- Basic Python coding skills (variables, data types, loops, functions)
- Familiarity with Pandas, NumPy, and Matplotlib is recommended
- Basic knowledge of trading/investing is helpful but not required

## Repository Contents
- `/notebooks` - Jupyter notebooks for each indicator and strategy
- `/data` - Financial datasets used in the course
- `/scripts` - Python scripts for backtesting and visualization
- `/projects` - Strategy implementations and optimization
- `/appendix` - Time series analysis and OOP foundations

## Key Libraries Used
- Pandas & NumPy (data manipulation)
- Plotly (interactive visualization)
- Matplotlib (static plots)

## Notes
This course emphasizes **practical, data-driven strategy validation**. You will learn to challenge trading ideas and identify which strategies are actually profitable.
